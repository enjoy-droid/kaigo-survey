# コンサルティング提案書 ／ 準備レポート

**テーマ:** 複数役割（議員・ケアマネ・管理者・経営者・産業ケアマネ）の「両立」支援
**作成日:** 2026-05-29
**ステータス:** ドラフト（クライアント面談前の社内準備版）

---

## 0. エグゼクティブサマリー

クライアントは、(1) 岡崎市議会議員、(2) ケアマネジャー、(3) 居宅介護支援事業所の管理者、(4) 経営者、(5) 産業ケアマネ という 5 つの役割を同時に担っている。本コンサルティングのゴールは「全部を頑張る」ことではなく、**役割を一本の戦略軸に束ね、持続可能に両立できる仕組みをつくる**ことにある。

- **共通の軸（仮説）:** 「岡崎市で、高齢者と"働きながら介護する人（ビジネスケアラー）"を地域ぐるみで支えるモデルをつくる」。議員＝制度・地域づくり、居宅＝現場、産業ケアマネ＝企業接点、経営者＝事業継続、ケアマネ＝専門性の源泉、として一気通貫で説明できる。
- **最大の機会:** 2025年4月施行の改正育児・介護休業法で企業の両立支援（個別周知・意向確認、相談体制整備等）が義務化され、**産業ケアマネの需要が制度的に裏付けられた**こと。経産省試算ではビジネスケアラーは2030年に約318万人・経済損失約9兆円規模。議員・居宅の地盤を持つクライアントは、岡崎市の地元企業に対し強い参入優位を持つ。
- **最大のリスク:** 時間の希少性と利益相反（議員 × 自社事業）。これを管理する仕組み（時間設計・ガバナンス・委譲）が両立の生命線。

---

## 1. クライアント・プロフィール（5つの役割）

| 役割 | 主な責務 | 提供する強み | 主な制約・リスク |
|------|---------|------------|----------------|
| ① 岡崎市議会議員 | 地域政策・予算・住民対応 | 行政/地域ネットワーク、政策発信力、信頼 | 公私の利益相反、議会日程の拘束、公人としての説明責任 |
| ② ケアマネジャー | 利用者のケアプラン作成・調整 | 現場の一次情報、専門資格、利用者からの信頼 | 担当件数の上限、対人負荷、更新研修 |
| ③ 居宅介護支援事業所 管理者 | 事業所運営・人員/品質管理 | 組織基盤、ケアマネ人材、地域の実績 | 管理者要件、加算・実地指導対応、人材確保 |
| ④ 経営者 | 事業戦略・収益・雇用 | 意思決定権、投資判断、ブランド | 資金繰り、後継/委譲、複数事業の分散 |
| ⑤ 産業ケアマネ | 企業の従業員の仕事と介護の両立支援 | ①〜④の全リソースを束ねた独自価値 | 新領域で実績/型が未確立、営業チャネル開拓 |

**着眼点:** ⑤産業ケアマネは①〜④の"出口"になり得る。議員ネットワークで地元企業へ接点を持ち、居宅の現場力を裏付けに、経営者として事業化する——この垂直統合がクライアント固有の競争優位。

## 2. 現状課題の仮説（面談で検証する）

> いずれも「仮説」。第3章の進め方とサーベイ（`03_survey.md`）で裏取りする。

1. **時間配分が役割ごとに最適化されていない** — 議会日程に現場・経営が振り回され、産業ケアマネに割く時間が後回しになっている可能性。
2. **役割間のシナジーが言語化・可視化されていない** — 個々に忙しいが、相互に活きる設計（紹介導線・共通ブランド）が弱い。
3. **権限委譲が進んでいない** — 管理者/経営者業務が属人化し、本人不在で回らない＝両立のボトルネック。
4. **産業ケアマネ事業のビジネスモデルが未確立** — 価格・契約形態（顧問/スポット）・提供メニュー・KPIが定まっていない。
5. **利益相反・コンプライアンスの整理が必要** — 議員の立場と自社事業/受注の線引き、説明責任の設計。

## 3. コンサルティングの進め方（4フェーズ）

```
Phase 1 現状把握    Phase 2 戦略設計    Phase 3 仕組み化    Phase 4 実装・伴走
  (2〜3週)            (3〜4週)            (4〜6週)            (継続)
─────────────────  ─────────────────  ─────────────────  ─────────────────
・5役割の棚卸し      ・共通軸の確定        ・時間/委譲設計      ・産業ケアマネ営業
・時間ログ取得        ・産業ケアマネ        ・ガバナンス/         ・KPIレビュー
・サーベイ実施          事業モデル設計        利益相反ルール      ・改善サイクル
・課題の構造化        ・ロードマップ        ・収益/価格設計
```

### Phase 1: 現状把握（2〜3週）
- 5 役割の責務・時間・収益・リスクの棚卸し（本人ヒアリング＋`03_survey.md` の自己診断パート）
- 1〜2週間の**時間ログ**取得（何にどれだけ時間を使っているか）
- 必要に応じ、地元企業/事業所内向けに**ニーズ調査サーベイ**を実施

### Phase 2: 戦略設計（3〜4週）
- 5 役割を束ねる**共通軸（パーパス）**の確定
- **産業ケアマネ事業のビジネスモデル**設計（顧客=地元企業、提供価値、価格、契約形態、提供メニュー）
- 3年ロードマップとマイルストーン

### Phase 3: 仕組み化（4〜6週）
- **時間設計**（役割ごとの時間ブロック／議会会期との両立カレンダー）
- **権限委譲・組織設計**（管理者業務の標準化、サブリーダー育成）
- **ガバナンス／利益相反ルール**（議員 × 自社事業の線引き、記録・開示）
- **収益・価格設計**（産業ケアマネ顧問料、居宅との相乗収益）

### Phase 4: 実装・伴走（継続）
- 産業ケアマネの営業・初回契約獲得の伴走
- 月次KPIレビューと改善

## 4. 産業ケアマネ事業の機会（重点テーマ）

### なぜ今か（市場の追い風）
- **改正育児・介護休業法（2024年5月成立／2025年4月1日施行）**: 介護関連で次が企業の**義務**に — ①介護に直面した労働者への介護休業等の**個別周知・意向確認**、②40歳到達時等の**早期の情報提供**、③介護休業・両立支援制度に関する**研修・相談窓口等の体制整備**。加えて、介護のための**テレワーク導入は努力義務**。→ 企業が「両立支援の専門家」を求める制度的動機が生まれた。
- **ビジネスケアラー（働きながら介護する人）の急増**: 経済産業省の試算では、団塊世代の後期高齢者化を背景に、**2030年に家族介護者は約833万人、うち約4割＝約318万人がビジネスケアラー**となる見込み。これに伴う**経済損失は約9兆円**と試算され、しかもその大半は離職そのものより「**働き続ける人の生産性低下**」によるもの。
- **経産省も後押し**: 経済産業省は2024年3月「**仕事と介護の両立支援に関する経営者向けガイドライン**」を公表し、全企業が取り組むべき経営課題と位置づけている。
- **地方では支援の担い手が不足**: 岡崎市の中堅・中小企業ほど、社内に両立支援ノウハウがない。

> 出典: 厚生労働省（育児・介護休業法 令和7年改正）、経済産業省「仕事と介護の両立支援に関する経営者向けガイドライン」（2024年3月）。提案前に各一次資料で最新の数値・施行内容を再確認のこと。

### クライアント固有の勝ち筋
- **議員の信頼・ネットワーク** → 地元企業・商工会議所への接点。
- **居宅事業所の現場力** → 「相談だけ」で終わらせず、実際のケアにつなげられる。
- **ワンストップ**: 制度説明 → 個別相談 → ケアマネ紹介 → 地域資源接続 を一社で提供できる稀少性。

### 想定オファリング（たたき台）
| メニュー | 内容 | 課金イメージ |
|---------|------|------------|
| 顧問契約 | 企業の両立支援体制づくり・相談窓口の外部委託 | 月額顧問料 |
| 従業員向けセミナー | 「仕事と介護の両立」研修 | 1回あたり |
| 個別相談（従業員） | 介護に直面した社員のケア相談 | 件数/時間 |
| 制度設計支援 | 就業規則・両立支援制度の整備支援 | プロジェクト |

> ⚠️ 価格・メニューは Phase 2 でクライアントと共創して確定。上表はディスカッションの叩き台。

## 5. KPI／成果指標（案）

- **両立（本人）指標**: 役割別の時間配分が計画通りか／本人不在でも事業所が回る日数／睡眠・健康セルフスコア。
- **事業指標**: 産業ケアマネ顧問契約数、相談対応件数、関連売上、居宅への紹介件数。
- **地域/社会指標**: 支援企業の介護離職の減少、相談からケア導入への接続率。
