# アンケート設問・調査票（kaigo-survey）

本コンサルティングで用いる調査票を 2 種類用意しています。目的に応じて使い分けてください。

- **調査票A：本人セルフ診断**（クライアント自身が回答。5役割の両立度を可視化）
- **調査票B：企業向け「仕事と介護の両立」ニーズ調査**（産業ケアマネ事業の見込み顧客＝地元企業の人事/管理職や従業員向け）

> 回答尺度の基本：特記なき設問は **5段階リッカート尺度**
> 1=全くあてはまらない／2=あまり／3=どちらとも／4=ややあてはまる／5=非常にあてはまる

---

## 調査票A：本人セルフ診断（5役割の両立度）

### A-0. 基本情報
1. 現在担っている役割（複数選択）：☐議員 ☐ケアマネ ☐居宅管理者 ☐経営者 ☐産業ケアマネ ☐その他（　　）
2. 1週間あたりの総稼働時間（おおよそ）：______ 時間

### A-1. 時間配分（直近1か月の実感）
各役割に **1週間あたり何時間** 使っているか、おおよそで記入：

| 役割 | 時間/週 | 本来は何時間にしたいか |
|------|--------|---------------------|
| ① 議員活動 | | |
| ② ケアマネ実務 | | |
| ③ 居宅の管理者業務 | | |
| ④ 経営（戦略・管理） | | |
| ⑤ 産業ケアマネ | | |
| 　その他（家庭・休息等） | | |

3. 時間配分は自分の意図どおりになっている。〔1–5〕
4. 想定外の対応（割り込み）に時間を奪われている。〔1–5〕

### A-2. 役割間の関係
5. 5つの役割は互いに良い相乗効果を生んでいる。〔1–5〕
6. 役割間で利益相反やコンプライアンス上の不安を感じることがある。〔1–5〕
7. ある役割の繁忙が、他の役割に悪影響を与えている。〔1–5〕
8. 最も相乗効果が高いと感じる役割の組み合わせは？（自由記述）

### A-3. 権限委譲・組織
9. 自分が不在でも居宅事業所は問題なく回る。〔1–5〕
10. 管理者業務の多くは標準化・委譲できている。〔1–5〕
11. 委譲を進めたいが進められない最大の理由は？（自由記述）

### A-4. 産業ケアマネ事業
12. 産業ケアマネとして提供する価値を一言で説明できる。〔1–5〕
13. 価格・契約形態（顧問/スポット等）が決まっている。〔1–5〕
14. 見込み顧客（地元企業）への接点・営業導線がある。〔1–5〕
15. この事業で1年後に達成したい状態は？（自由記述）

### A-5. 持続可能性・健康
16. 十分な睡眠・休息がとれている。〔1–5〕
17. 現在の働き方を3年続けられる自信がある。〔1–5〕
18. 今いちばん解決したい「両立の悩み」は？（自由記述・最重要）

## 調査票B：企業向け「仕事と介護の両立」ニーズ調査

> 用途：産業ケアマネ事業の見込み顧客となる **地元企業の人事・管理職／従業員** 向け。
> 配布方法の目安：Googleフォーム等のWebフォーム。所要 5〜7分。

### 回答者属性
- B-0a. 立場：☐経営者/役員 ☐人事・総務 ☐管理職 ☐一般従業員
- B-0b. 従業員規模：☐〜29名 ☐30〜99名 ☐100〜299名 ☐300名以上
- B-0c. 業種：（　　　　）

### セクション1：現状認識
1. 自社に、家族の介護をしながら働いている従業員がいる（と思う）。〔1–5 / わからない〕
2. 介護を理由に、休職・離職・働き方変更をした従業員がいる。〔はい／いいえ／わからない〕
3. 今後5年で、介護に直面する従業員が増えると思う。〔1–5〕

### セクション2：制度・体制
4. 仕事と介護の両立を支援する社内制度（介護休業・時短等）が整っている。〔1–5〕
5. 改正育児・介護休業法（2025年4月〜）への対応が完了している。〔できている／対応中／未着手／内容を知らない〕
6. 介護に直面した従業員が相談できる窓口がある。〔ある／ない／わからない〕

### セクション3：課題・ニーズ（事業の核心）
7. 介護に関する以下の課題のうち、自社にあてはまるもの（複数選択）
   - ☐ 相談できる専門家が社内にいない
   - ☐ 制度はあるが使われていない／知られていない
   - ☐ 管理職が介護の相談を受けても対応できない
   - ☐ 介護離職による人材流出が不安
   - ☐ 法改正対応の負担が大きい
   - ☐ 特に課題はない
8. 「介護の専門家（産業ケアマネ）」による以下の支援に関心がある（複数選択）
   - ☐ 従業員向けの個別介護相談窓口（外部委託）
   - ☐ 「仕事と介護の両立」研修・セミナー
   - ☐ 両立支援制度・就業規則の整備支援
   - ☐ 管理職向けの対応研修
   - ☐ 法改正対応のアドバイザリー
9. こうした外部支援サービスを利用したいと思う。〔1–5〕

### セクション4：導入条件
10. 導入を検討する際に重視する点（最大2つ）：☐費用 ☐実績/信頼 ☐地元であること ☐対応範囲の広さ ☐スピード
11. 費用感として妥当だと思う形態：☐月額顧問 ☐スポット相談（都度） ☐研修1回単位 ☐わからない
12. サービスについて詳しい説明を希望する。〔希望する／しない〕
    - 希望する場合の連絡先：（任意：会社名・担当者・メール）

### 自由記述
13. 仕事と介護の両立について、社内で困っていること・期待することがあればご記入ください。

## 集計・分析の方針（実施者向けメモ）

- **調査票A** は本人の主観可視化が目的。レーダーチャート（役割別の「現状時間 vs 理想時間」）と、設問16–18のセルフスコアを Phase 1 の議論の出発点にする。
- **調査票B** は事業仮説の検証。重点は **設問7・8・9・11**（課題→関心→支払意思→価格形態）。クロス集計軸＝従業員規模 × 関心度で、初期ターゲット企業群を特定する。
- 個人情報（B-12の連絡先等）は同意取得・利用目的の明示・適切な管理を徹底（議員という立場上、特に丁寧に）。
- データ集計用テンプレートが必要であれば、CSV/スプレッドシート雛形を別途作成可能。

> ⚠️ 設問5の法改正の記述は作成時点の理解に基づく。配布前に最新の条文・施行内容を確認すること。
