# 5つの役割を、一本の軸へ

## 議員 × ケアマネ × 居宅管理者 × 経営者 × 産業ケアマネ
### ― 両立を支えるコンサルティング 提案 ―

2026-05-29　ドラフト

---

# 本日のゴール

1. クライアントの **5つの役割** を整理する
2. それらを束ねる **共通の軸（仮説）** を共有する
3. 「両立」を持続可能にする **進め方** を合意する

> 「全部を頑張る」のではなく、**仕組みで両立する**。

---

# クライアントの5つの顔

| 役割 | 立場 |
|------|------|
| ① 岡崎市議会議員 | 地域・制度をつくる |
| ② ケアマネジャー | 現場で支える |
| ③ 居宅介護支援事業所 管理者 | 組織を運営する |
| ④ 経営者 | 事業を継続させる |
| ⑤ 産業ケアマネ | 企業の従業員を支える |

---

<!-- _class: lead -->

# 課題：役割が"バラバラ"に消費されていないか？

- 議会日程に現場・経営が振り回される
- シナジーが言語化されていない
- 本人に依存し、不在だと回らない
- 産業ケアマネ事業の「型」が未確立

---

# 仮説：5つは一本の軸でつながる

> **「岡崎市で、高齢者と "働きながら介護する人" を地域ぐるみで支える」**

```
  ① 議員 ── 制度・地域づくり
  ② ケアマネ ── 専門性の源泉
  ③ 居宅管理者 ── 現場の実行基盤
  ④ 経営者 ── 事業の継続性
  ⑤ 産業ケアマネ ── 企業への出口
            ↓
      地域の両立支援モデル
```

# 最大の機会：産業ケアマネ

### 制度の追い風（2025年4月施行）
改正育児・介護休業法で、企業に **個別周知・意向確認／相談体制整備** が義務化

### ビジネスケアラーの急増（経産省試算）
**2030年に約318万人**・経済損失 **約9兆円**。介護離職と生産性低下が経営課題に。

→ 企業が「両立支援の専門家」を求める時代へ

---

# クライアント固有の勝ち筋

- **議員の信頼・ネットワーク** → 地元企業への接点
- **居宅の現場力** → 相談で終わらせず、ケアにつなぐ
- **ワンストップ** → 制度説明〜個別相談〜ケア導入を一社で

> 岡崎市で、この垂直統合ができるのはほぼ唯一無二。

---

# 進め方：4フェーズ

| Phase | 期間 | 主な内容 |
|-------|------|---------|
| 1 現状把握 | 2〜3週 | 5役割の棚卸し・時間ログ・サーベイ |
| 2 戦略設計 | 3〜4週 | 共通軸確定・産業ケアマネ事業設計 |
| 3 仕組み化 | 4〜6週 | 時間設計・委譲・ガバナンス・価格 |
| 4 実装伴走 | 継続 | 営業伴走・月次KPIレビュー |

---

# Phase 1 の宿題（まず着手）

- [ ] 議会の **会期カレンダー** を入手（最優先で固定）
- [ ] 1〜2週間の **時間ログ** を記録
- [ ] **サーベイ** 実施（自己診断＋必要なら企業ニーズ調査）

---

# 成果指標（案）

- **両立（本人）**：役割別時間が計画通りか／不在でも回る日数／健康スコア
- **事業**：顧問契約数・相談件数・関連売上・居宅紹介数
- **地域/社会**：支援企業の介護離職減少・ケア導入への接続率
